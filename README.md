# Словничок

Вебзастосунок для вивчення англійських слів, ідіом і граматики. Працює в браузері на телефоні й ноутбуці.

- **Практика слів** з інтервальним повторенням (система Лейтнера), три режими: UA→EN, EN→UA, картки. Вимова через Web Speech API.
- **Граматика**: теорія всіх 12 часів і основних правил (артиклі, умовні речення, пасив, модальні дієслова, ступені порівняння, gerund/infinitive, непряма мова), вправи та змішана практика, яка частіше дає слабкі теми.
- **Словник**: пошук, фільтри, редагування, масовий імпорт.

## Де зберігаються дані

Бази даних немає.

1. **localStorage браузера** — основне сховище. Дані зберігаються між сесіями й не скидаються під час нових деплоїв.
2. **Приватний GitHub Gist** — синхронізація між пристроями. На вкладці ☁ «Синхронізація» вставте GitHub-токен з дозволом `gist` ([створити токен](https://github.com/settings/tokens/new?scopes=gist&description=Slovnychok)). На кожному пристрої використовуйте той самий токен: застосунок сам знайде gist із файлом `slovnychok-data.json`.

Синхронізація працює за схемою «завантажити → об'єднати → надіслати». Для кожного слова й теми граматики перемагає найсвіжіша зміна. Видалення запам'ятовуються, тож видалене слово не «воскресне» з іншого пристрою. Без мережі все працює локально й синхронізується, щойно з'явиться зв'язок.

Додатково є експорт та імпорт JSON-бекапу. Імпорт розуміє і формат першої HTML-версії.

## Розробка

```bash
npm install
npm run dev      # http://localhost:5173 (і в локальній мережі — зручно перевіряти з телефона)
npm run build    # збірка в dist/
```

## Деплой (GitHub Pages)

1. Запуште репозиторій на GitHub.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Кожен push у `main` збирає й деплоїть застосунок (`.github/workflows/deploy.yml`).

Адреса: `https://<user>.github.io/<repo>/`. На телефоні можна додати застосунок на головний екран через «Поділитися → На початковий екран».
